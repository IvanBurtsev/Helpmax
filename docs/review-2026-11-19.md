## Проверено по официальной документации MAX

- База: `https://platform-api2.max.ru` (не `platform-api.max.ru`).
- Токен: только заголовок `Authorization: <access_token>`.
- Лимит: 30 rps.
- Webhook: HTTPS/443, доверенный сертификат, полная цепочка; HTTP и
  самоподписанные запрещены с 25.05.2026.
- Ответ webhook: HTTP 200 в течение 30 секунд; до 10 ретраев, затем отписка.
- Секрет: `secret` 5–256 символов `[A-Za-z0-9_-]`, заголовок
  `X-Max-Bot-Api-Secret`.
- Deep link: `https://max.ru/<botName>?start=<payload>`, payload ≤ 128 символов.
- Официальный JS SDK: `@maxhub/max-bot-api` (репозиторий
  `max-messenger/max-bot-api-client-ts`).

Ссылки: <https://dev.max.ru/docs-api/>,
<https://dev.max.ru/docs-api/methods/POST/subscriptions/>,
<https://dev.max.ru/docs/chatbots/bots-coding/prepare/>.

## Что нужно, чтобы включить вживую

1. **`LLM_API_KEY`** — подсказки через LLM. Используем **AITUNNEL**
   (`https://api.aitunnel.ru/v1`, ключ `sk-aitunnel-…`): РФ, оплата в рублях, без
   VPN, OpenAI-совместимо. Модель `deepseek-v4.1-flash`. Без ключа подсказки идут
   из гайдов (откат).
2. **`STT_API_KEY`** — распознавание голоса. AITUNNEL даёт его тем же ключом
   (`/audio/transcriptions`, модель `whisper-large-v3-turbo`). Без ключа голосовые
   не принимаются (просим текстом).
3. **Ревью гайдов юристом** — снять `review_status: draft`.
4. **Ротация `MAX_BOT_TOKEN`** — токен в чате скомпрометирован.
